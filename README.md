# AI Disaster Response Assistant

## Purpose
A production-style hackathon project aimed at building an AI-powered assistant for disaster response. The application will help classify disasters, assess urgency, extract structured incident reports, summarize situations, and analyze images from disaster zones.

## Development Stage
Currently in **Phase 1: Project Foundation**. The repository contains the initial setup for a full-stack application. AI, map integrations, and databases are yet to be implemented.

## Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS
- **Backend**: Python, FastAPI
- **Database (Planned)**: PostgreSQL
- **AI Integrations (Planned)**: LLM API for text and image analysis
- **Maps (Planned)**: Leaflet / OpenStreetMap

## Future Features
- Disaster classification and urgency assessment via AI.
- Structured incident extraction from unstructured text.
- Interactive map showing disaster incidents.
- Image analysis for assessing damage in disaster zones.
